PDF Merger

Keep your documents together and in order.

Combine supported PDF files locally in your browser. Review file order and download the merged document without a server upload.

If the tool does not load, open it directly.

How to use this tool

  1. Choose the PDF files to combine in the intended order.
  2. Review supported-file and size limits before processing.
  3. Process the merge, download the result and check every page before sharing it.

How processing works

Output pages are appended in selected file order, preserving each source file’s page order and page sizes.

Worked example

Select a two-page invoice followed by a one-page receipt to create a three-page PDF with the invoice first.

What to check before using the result

Up to 10 PDFs, 20 MB each, 60 MB total, and 200 pages. Password-protected or damaged PDFs are unsupported. Digital signatures, bookmarks, document-level forms and metadata are not preserved. Review the result before sharing. Uses bundled MIT-licensed pdf-lib 1.17.1.

Are signatures and interactive features preserved?

Do not rely on a merge to preserve digital signature validity, interactive forms, attachments or advanced document behavior. Keep the original files and review the output. Encrypted or unsupported PDFs may be rejected.
