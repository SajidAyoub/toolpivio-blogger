Create a PDF from supported images locally in your browser. Review page order, output size and image quality before downloading.

If the tool does not load, open it directly.

How to use this tool

  1. Select the supported images you want to include.
  2. Review their order and the available page settings.
  3. Process the images into a PDF and download the generated document.

How processing works

Each image is scaled proportionally to fit the printable page area: scale = min(available width ÷ image width, available height ÷ image height).

Worked example

Select three product images, choose A4 portrait with 10 mm margins, and process them into a three-page PDF in the displayed input order.

What to check before using the result

Up to 10 images, 20 MB each, 60 MB total, and 32 million pixels per image. Images are embedded as JPG on white; there is no OCR or searchable text. Selection order is output order. Uses bundled MIT-licensed pdf-lib 1.17.1.

Will this make scanned text searchable?

No. This places image content on PDF pages. It does not perform optical character recognition or turn image text into selectable text.
