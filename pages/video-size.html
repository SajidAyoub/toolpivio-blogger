How to use this tool

  1. Choose whether to estimate file size or the video bitrate budget.
  2. Enter duration and audio bitrate, then supply either video bitrate or target file size as labeled.
  3. Calculate an estimate and allow additional space for container overhead and encoder variation.

Formula and units

File bytes = duration in seconds × (video Mbps + audio kbps ÷ 1,000) × 1,000,000 ÷ 8. Target video Mbps = target MB × 8 ÷ seconds − audio Mbps.

Worked example

A 60-second video at 8 Mbps plus 128 kbps audio is about 60.96 MB, or 58.136 MiB. A 60.96 MB target gives an 8 Mbps video budget.

What to check before using the result

Uses decimal MB and Mbps, with MiB also shown for size estimates. Assumes average bitrates; container overhead, variable-rate peaks and encoding quality affect real files. This tool does not encode or upload video.

Should I include audio bitrate?

Yes. Use the combined average bitrate of the video, audio and any other streams for a closer estimate. Variable bitrate and container overhead can change the final file size.
