How to use this tool

  1. Choose a supported source image from your device.
  2. Select an output format and quality level.
  3. Process the file, compare the output size with the original and download only if the result suits your needs.

How processing works

Size reduction (%) = (1 − output bytes ÷ input bytes) × 100. A negative reduction means the new file is larger.

Worked example

An image reduced from 1 MB to 400 KB saves about 60% using decimal byte units. Actual savings depend on image content, starting format, and quality.

What to check before using the result

Quality is lossy for JPG and WebP; smaller output is not guaranteed. Dimensions are preserved. JPG replaces transparency with white. Maximum input is 20 MB and 32 million pixels.

Why can the compressed image be larger?

A small or already optimized original may encode less efficiently with the selected settings. Check the measured output size; a quality setting cannot guarantee a smaller file.
