Check the horizontal and vertical resolution of an image at its intended physical print size. This measures pixels per inch (PPI), often informally called print DPI.

How to use this tool

  1. Enter the image width and height in pixels from the file properties.
  2. Enter the intended print dimensions and choose inches or centimeters.
  3. Calculate to check both axes. Reset clears your measurements.

Formula and units

Horizontal PPI = image width in pixels ÷ print width in inches. Vertical PPI = image height in pixels ÷ print height in inches. Inches = centimeters ÷ 2.54.

Worked example

An image measuring 3,000 × 2,400 pixels printed at 10 × 8 inches gives 300 PPI on both axes. The same print size is 25.4 × 20.32 centimeters.

What to check before using the result

Pixel dimensions must be positive whole numbers. PPI describes image sampling, while printer DPI describes ink dots. Around 300 PPI is a common starting point for close-viewed prints, not a universal requirement. Different results on the two axes can indicate a shape mismatch; ask your printer about cropping, stretching, viewing distance and bleed.

Does changing a file's DPI metadata create detail?

No. Changing a resolution label does not add image detail. The available pixels and final physical dimensions determine PPI. Upscaling may add pixels, but it cannot recover original detail that was never captured.
