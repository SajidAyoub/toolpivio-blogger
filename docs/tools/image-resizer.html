Image Resizer

Resize an image in your browser with a local preview and download. Set pixel dimensions and check aspect ratio without uploading your file.

Free to use. No sign-up. Calculations and selected files are processed in your browser.

If the tool does not load, open it directly.

How to use this tool

  1. Choose a supported image from your device.
  2. Enter the desired pixel dimensions and choose whether to preserve the aspect ratio.
  3. Process the image, inspect the preview and download the generated file.

How processing works

With proportions locked, output height = output width × original height ÷ original width, rounded to the nearest pixel.

Worked example

A 640 × 480 image resized to 320 pixels wide becomes 320 × 240 pixels with proportions locked.

What to check before using the result

Supports JPG, PNG, and WebP up to 20 MB and 32 million pixels. Maximum output dimension is 12,000 pixels. Enlarging an image does not create additional photographic detail. JPEG uses a white background.

Will enlarging my image recover missing detail?

No. Browser resizing resamples existing pixels. Enlarging an image can make it softer and does not restore detail that was absent from the original.
