# Installation

Use [V3_INSTALL.md](V3_INSTALL.md) for the current theme backup, manual installation and rollback steps. Install only `releases/ToolPivio_V3_Ready_For_Blogger.xml` from an approved commit. The restored V2 reference remains unchanged.

**Do not upload `dist/toolpivio.xml`.** It is a superseded generator artifact with a different page renderer and is retained only as historical source.

Use [TOOLS_DEPLOYMENT.md](TOOLS_DEPLOYMENT.md) for GitHub Pages and selective registered Blogger page publishing. Theme installation, Pages deployment and Blogger content publishing are separate operations. No PR automatically installs the XML theme, and no PR should be auto-merged.
