# Blogger Search Descriptions

Enter these descriptions in Blogger → Pages → the page → Search Description after the page is published and its actual URL has been checked. The owner must enable Search Description under Blogger Settings → Meta tags first. These are proposed field values; repository body HTML does not set this page-editor field.

Keep the three established page titles unchanged. New page titles below match the tool manifests; their actual Blogger permalinks must come from the publisher response, not this table. Hosted guides receive these descriptions automatically at build time.

| Page title | Description |
| --- | --- |
| ROAS Calculator | Calculate return on ad spend from attributed revenue and campaign cost. See ROAS as a multiple and percentage, with a worked example and limitations. |
| Profit Margin Calculator | Calculate profit and profit margin from revenue and total cost. Understand negative margins and the difference between margin and markup. |
| Print DPI Calculator | Check image pixels per inch at a chosen print size in inches or centimeters. Calculate both axes and understand PPI, DPI and aspect-ratio limits. |
| CPC Calculator | Calculate average cost per click from ad spend and clicks. Compare campaign traffic costs using matching periods and consistent attribution. |
| CPM Calculator | Calculate advertising cost per thousand impressions from spend and served impressions. See the CPM formula and a worked campaign example. |
| CTR Calculator | Calculate click-through rate as clicks divided by impressions. Check engagement using consistent campaign and reporting-period counts. |
| CPA Calculator | Calculate average cost per acquisition or action from campaign spend and conversions. Keep conversion definitions and reporting periods consistent. |
| Discount Calculator | Calculate a sale price and savings from an original price and percentage discount. Check the price before tax, shipping or other extra charges. |
| Markup Calculator | Calculate markup percentage and profit from unit cost and selling price. Compare markup on cost with profit margin on revenue. |
| Break-even Calculator | Estimate break-even sales units from fixed costs, selling price and variable unit cost. See the contribution-margin formula and whole-unit rounding. |
| Bleed & Trim Calculator | Calculate artwork size from trim dimensions and bleed on each side. Confirm print production dimensions before sending a file to your printer. |
| Print Size Converter | Convert print dimensions between millimeters, inches and pixels at a chosen PPI. Understand exact physical units and rounded pixel dimensions. |
| Video File Size & Bitrate Calculator | Estimate video file size from duration and combined bitrate, or estimate bitrate from file size. Understand decimal units and container overhead. |
| Frames & Duration Converter | Convert video frames to duration or duration to frame count at a chosen frame rate. Check non-integer frame rates and whole-frame rounding. |
| Image Resizer | Resize an image in your browser with a local preview and download. Set pixel dimensions and check aspect ratio without uploading your file. |
| Image Compressor | Compress a supported image locally with JPEG or WebP quality controls. Compare the output size and preview before downloading. |
| Image Format Converter | Convert a supported image to JPEG, PNG or WebP in your browser. Preview the result and understand transparency and metadata limits. |
| Images to PDF | Create a PDF from supported images locally in your browser. Review page order, output size and image quality before downloading. |
| PDF Merger | Combine supported PDF files locally in your browser. Review file order and download the merged document without a server upload. |

Suggested site description: “Free calculators and browser tools for marketing, e-commerce, printing, video, images and PDFs. Clear inputs, useful examples and local processing.”

Inspect the rendered page source after saving. Each document should have one description meta tag. If Blogger already emits a page-specific description, a theme fallback must not emit a duplicate.
